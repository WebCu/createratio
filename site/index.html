Keep it to yourself.

Your extension activity stays in your browser. The extension has no account or analytics, collects no post text, and uploads no activity data.

Start with a small extension.

Get CreateRatio from the Chrome Web Store or Firefox Add-ons. No developer tools needed. Save your X and LinkedIn drafts before installing: existing tabs are redirected to the access gate. Save Instagram and TikTok drafts before enabling them, too.

To add Instagram or TikTok, open CreateRatio’s Settings → Websites and turn on Limit & track for that site. Both start Off. Turning a site Off removes limits and stops new creation-score measurements, without deleting history.

Install in Chrome
  1. Open the Chrome Web Store listing and choose Add to Chrome.
  2. Confirm the installation, then pin CreateRatio from Chrome’s extensions menu.
  3. Visit X or LinkedIn to set an intention and start your first session. Adjust access limits in Settings.
Install in Firefox
  1. Open the Firefox Add-ons listing and choose Add to Firefox.
  2. Confirm the installation.
  3. Visit X or LinkedIn to set an intention and start your first session. Adjust access limits in Settings.
Build from source (Chrome, Edge, Firefox)

You’ll need Git, stable Node.js 24.x and pnpm 12.x. The extension has no runtime dependencies.

git clone https://github.com/WebCu/createratio.git
cd createratio
pnpm install --frozen-lockfile
pnpm build
  1. Chrome 111+ or Edge: open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, and select dist/chrome or dist/edge.
  2. Firefox 140+: open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, select dist/firefox/manifest.json, then refresh your enabled site tabs.

The temporary Firefox source install is removed when Firefox restarts; use the Firefox Add-ons listing above for a permanent installation. Edge is available as a development build, not a store release.
