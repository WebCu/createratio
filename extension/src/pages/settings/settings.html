Site access

  • On: timed access plus creation-score tracking of creating/consuming time and actions. Each new session needs an intention and 60-second wait; the site blocks when time runs out.
  • Off: free access; no gate, wait, timer or new creation-score measurements. Keeps history and saved duration; cancels the current budget, pending wait and refill. Turning On starts fresh unless above-goal access applies.
  • Shared active time: all tabs for a site share one budget. All active-tab time counts, not just consuming. Switching away pauses it.

Session times, Default and daily refills
  • From Default follows the Default time. A Custom time stays unchanged when Default changes; Use Default removes that override.
  • Time changes apply to new sessions and midnight refills, not the current budget.
  • At local midnight, unused or exhausted session budgets refill to the configured duration once per day, without accumulating. Sites you have never opened stay blocked.
  • Manually ending a session or turning Off cancels its daily refill.
