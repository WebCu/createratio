# Security policy

## Reporting a vulnerability

Report security vulnerabilities privately through GitHub: open the
repository's **Security** tab and choose
[**Report a vulnerability**](https://github.com/WebCu/createratio/security/advisories/new).

Do not open a public issue, pull request, or discussion for a vulnerability.
Keep exploit details, credentials, intention text, private activity, and CSV
exports out of public channels.

## Supported versions

Security fixes go into the latest release and are not backported. Update to the
newest version before reporting.

| Version | Supported |
| --- | --- |
| Latest [release](https://github.com/WebCu/createratio/releases/latest) | Yes |
| Older releases | No |
