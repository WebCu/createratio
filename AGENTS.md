# Working on CreateRatio

Before changing code, read [CONTRIBUTING.md](CONTRIBUTING.md) for project
principles and [coding standards](CONTRIBUTING.md#coding-standards), and
[GLOSSARY.md](GLOSSARY.md) for product terms.

- For features, bug fixes, test changes, or refactors, follow
  [docs/testing.md](docs/testing.md#strategy-and-completion) for the tracer-bullet
  workflow, acceptance criteria, test interfaces, and completion gate.
- For extension source moves, packaged paths, or manifest changes, read
  [extension/README.md](extension/README.md#layout-and-installation).
- For site integrations or selectors, read
  [extension/sites/README.md](extension/sites/README.md).
- For dependencies, toolchain changes, or CI, read
  [docs/dependencies.md](docs/dependencies.md).

Before reporting completion, inspect the diff and run the required checks in
`docs/testing.md`. Report commands, failures, and unverified browser behavior.
Keep standards in `CONTRIBUTING.md` and verification guidance in
`docs/testing.md`; update those sources rather than duplicating their rules here.
